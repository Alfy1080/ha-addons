# Artifactory — Home Assistant Add-on

![Version](https://img.shields.io/badge/version-1.0.5-blue)
![Supports amd64](https://img.shields.io/badge/amd64-yes-green)
![Supports aarch64](https://img.shields.io/badge/aarch64-yes-green)

File explorer & asset manager for Home Assistant. Upload, browse, and manage static assets via web UI and REST API. Designed for LLM-driven asset workflows.

## Features

- 📁 Browse files and directories on your HA server
- ⬆️ Upload files via drag-and-drop, multipart form, or base64 JSON API
- 🔗 Fetch files from external URLs
- 🖼️ Preview images, video, audio, PDF, and text files
- 🤖 REST API designed for LLM/MCP integration
- 🔒 Configurable read-write and read-only paths
- 🌙 Dark theme UI

## Installation

1. Add this repository to your Home Assistant add-on store
2. Install the "Artifactory" add-on
3. Configure write and read paths as needed
4. Start the add-on
5. Access via the sidebar or API
